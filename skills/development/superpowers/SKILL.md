# Superpowers

A zero-dependency development methodology plugin with 14 integrated skills that enforce a structured software development lifecycle.

## Sub-skills

| Skill | Purpose |
|---|---|
| **using-superpowers** | How to find and invoke superpowers skills |
| **brainstorming** | Idea exploration before writing code |
| **writing-plans** | Structured design and implementation plans |
| **executing-plans** | Step-by-step plan execution |
| **subagent-driven-development** | Dispatch subagents for parallel feature work |
| **test-driven-development** | Write tests first, then implement |
| **systematic-debugging** | Structured debugging process |
| **requesting-code-review** | Prepare and request peer code review |
| **receiving-code-review** | Process and apply code review feedback |
| **verification-before-completion** | Verify work before marking complete |
| **finishing-a-development-branch** | Clean up and merge completed work |
| **dispatching-parallel-agents** | Coordinate parallel agent execution |
| **using-git-worktrees** | Isolate work in git worktrees |
| **writing-skills** | Create and improve agent skills |

## Usage

Invoke via `Skill` tool with skill name `superpowers`. Load individual sub-skills as needed using `using-superpowers` first to understand the framework.
