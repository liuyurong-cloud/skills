医药物流管理系统 Architecture

Vue 3 + Vite + Element Plus · Pharmaceutical Distribution Admin System

Tech Stack

  • • Vue 3 Composition API + Vite 5
  • • Element Plus UI (Chinese locale)
  • • TanStack Query + Pinia state
  • • Axios HTTP + Vue Router 4
  • • SCSS styling · JetBrains Mono

Core Business Modules

  • • Sales Management (orders, customers, shipping)
  • • Procurement (purchase orders, suppliers)
  • • Warehouse (stock in/out, inventory tracking)
  • • Finance (invoices, payments, refunds)
  • • System Admin (users, roles, permissions)

Key Capabilities

  • • Token-based auth (Access-Token-Pc header)
  • • Print/Export PDF & PNG (html2canvas + jsPDF)
  • • Audit logging (v-click-log directive)
  • • Excel import/export · PDF preview
  • • UDI barcode scanning support
